# TestQua31 Appium Project

## Project Overview
This project demonstrates **automated mobile testing** using Appium and Python.  
It contains test scripts for the **Google Calculator app** on an Android emulator.

## Prerequisites
- Python 3.13+
- Appium Desktop 3.x
- Android Emulator (Pixel 3 recommended)
- Java JDK 8+
- ADB installed and configured in PATH
- Git (optional, for version control)
