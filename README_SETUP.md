\# TestQua31 Appium Setup Guide



\## Requirements

\- Windows 10 / 11

\- Python 3.9+

\- Java JDK 8 or higher

\- Node.js (LTS)

\- Appium Server

\- Android Studio

\- Android SDK (platform-tools, build-tools)

\- Android Emulator or real Android device

\- Git



\## Folder Structure

/TestQua31-Appium/

&nbsp; /code/python/

&nbsp; /docs/

&nbsp; /reports/

&nbsp; /screenshots/

&nbsp; /videos/



\## Setup Instructions

1\. Install all requirements above

2\. Set ANDROID\_HOME and add platform-tools to PATH

3\. Start Appium Server

4\. Run test scripts from /code/python
